PASANG WEB DI DOMAIN BARU  (gvsmartpay2.vercel.app)
====================================================
1. Isi zip ini harus ada di ROOT repo yang disambungkan ke project Vercel
   (index.html, api/, vercel.json, package.json, sw.js, dan seterusnya, tidak di dalam folder lain).
   Setelah deploy: https://gvsmartpay2.vercel.app harus menampilkan GVSMARTPAY.

2. Vercel > Settings > Environment Variables (project baru kosong, isi semuanya):
      FIREBASE_SERVICE_ACCOUNT   (isi JSON akun layanan Firebase project gvsmartpay)
      HAYBI_USERNAME, HAYBI_API_KEY
      MANGBELI_API_KEY, MANGBELI_API_SECRET
      PUNYAKIOS_API_KEY, PUNYAKIOS_API_SECRET
      CRON_SECRET                (minimal 16 karakter; untuk harga otomatis dan cron)
      RESELLER_WEBHOOK_SECRET    (kalau dipakai)
      PUSH_ACK_SECRET            (kalau sudah pernah diisi di project lama, isi sama)
   Salin nilainya dari project Vercel lama, lalu Redeploy.

3. Firebase Console > Authentication > Settings > Authorized domains > Add domain:
      gvsmartpay2.vercel.app
   (tanpa ini login di domain baru gagal)

4. Daftarkan ulang alamat webhook di panel reseller (domain berubah):
      https://gvsmartpay2.vercel.app/api/haybi-callback
      https://gvsmartpay2.vercel.app/api/punyakios-callback
      https://gvsmartpay2.vercel.app/api/mangbeli-callback

5. Firestore Rules: tidak berubah (project Firebase sama).
6. Harga otomatis: lihat CARA-HARGA-OTOMATIS.txt.
