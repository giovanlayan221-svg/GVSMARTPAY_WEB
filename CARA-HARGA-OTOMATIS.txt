HARGA OTOMATIS  (harga jual = modal reseller terbaru + margin tetap, naik dan turun, tiap 12 jam)
==================================================================================================
Contoh: modal reseller 5.600, harga di web 5.800  -> margin 200.
        Reseller turun jadi 5.000                  -> web otomatis jadi 5.200.
        Reseller naik jadi 6.100                   -> web otomatis jadi 6.300.
Berlaku untuk produk HAYBI dan MangBeli. Produk PunyaKios tidak ikut otomatis.

File terkait: api/_hargasync.js, api/harga-sync.js, api/haybi.js (aksi harga_sync),
              vercel.json (maxDuration), index.html (kartu di Admin > Produk).

LANGKAH PASANG (sekali saja)
1. Vercel > Settings > Environment Variables, tambah:
      CRON_SECRET = (karangan acak, minimal 16 karakter)
   (HAYBI_USERNAME, HAYBI_API_KEY, MANGBELI_*, FIREBASE_SERVICE_ACCOUNT harus sudah ada.)
2. Deploy ulang.
3. Buka app > Admin > Produk > kartu "Harga otomatis":
      a. Tekan "Simulasi dulu": lihat daftar harga yang akan berubah (belum disimpan).
      b. Kalau angkanya benar, tekan "Terapkan sekarang". Pada run pertama, margin tiap produk
         dicatat dari selisih (harga jual sekarang - modal reseller sekarang).
      c. Tekan "Aktifkan otomatis".
4. Pasang jadwal 12 jam (pilih salah satu):

   A) Vercel PRO  -> tambahkan di vercel.json bagian "crons":
        { "path": "/api/harga-sync", "schedule": "0 */12 * * *" }
      Jalan jam 00 dan 12 UTC (= 07 dan 19 WIB).

   B) Vercel HOBBY (gratis) -> cron Vercel cuma boleh 1x/hari, JANGAN ditaruh di vercel.json
      (deploy akan gagal). Pakai penjadwal gratis, mis. cron-job.org:
        URL      : https://gvsmartpay2.vercel.app/api/harga-sync
        Metode   : GET
        Header   : Authorization: Bearer <isi CRON_SECRET>
        Interval : tiap 12 jam
      Hasil jalannya (jam terakhir, jumlah harga berubah) tampil di kartu Admin > Produk.

PENGAMAN
- Produk tanpa SKU, provider PunyaKios, atau autoPrice=false di Firestore dilewati.
- Daftar produk reseller kosong / format tak dikenali -> tidak ada harga diubah.
- Harga jual di bawah modal, kode ganda, atau modal loncat >50% -> dilewati & dilaporkan di hasil.
- Mau kunci satu produk supaya tidak ikut otomatis: set field autoPrice = false.
- Mau ubah margin satu produk: ubah field margin di Firestore (products/<id>).
- Pesanan yang sedang dibayar tepat saat harga naik bisa ditolak server (anti-manipulasi harga); pelanggan tinggal ulangi.
